# homework-22 — SHOP.CO

Вёрстка лендинга интернет-магазина одежды SHOP.CO по макету.
Чистые HTML + CSS + JavaScript, без фреймворков и сборки.

## Запуск

Открыть `index.html` в браузере. Либо поднять локальный сервер:

```bash
python3 -m http.server 8777
# http://localhost:8777
```

## Структура

```
index.html    разметка
styles.css    стили и адаптив
script.js     вся логика (данные о товарах — массив PRODUCTS)
img/          фотографии товаров, hero и категорий
```

## Что реализовано

- **Каталог** — рендер карточек из данных, рейтинги, скидки со старой ценой и процентом
- **Корзина** — добавление, изменение количества, удаление, подсчёт суммы;
  сохраняется в `localStorage` и переживает перезагрузку
- **Карточка товара** — модальное окно с описанием и выбором размера
- **Поиск** — живой, по названию, категории и стилю; работает и в шапке, и в мобильном меню
- **Фильтры** — меню Shop, «On Sale» и карточки Casual / Formal / Party / Gym
- **Слайдер отзывов** — стрелки и свайп
- **Форма подписки** — с валидацией e-mail
- **Адаптив** — брейкпоинты 1100 / 900 / 640 / 420 px, бургер-меню
